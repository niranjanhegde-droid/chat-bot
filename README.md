# Flask Chatbot with Login and Chat History

This is a simple chatbot web application built using **Flask**, integrated with the **OpenRouter API** (e.g., LLaMA 3 models). It supports user registration, login, and stores chat history per user.

## 🚀 Features

- User authentication (Register / Login / Logout)
- Chatbot powered by OpenRouter API (e.g., LLaMA 3, Mixtral, etc.)
- Chat history saved for each user
- HTML pages styled with Bootstrap 5
- Secure with `.env` for API and secret keys

## 🛠️ Technologies

- Python + Flask
- Jinja2 Templates
- SQLite + SQLAlchemy
- Bootstrap 5
- OpenRouter API
